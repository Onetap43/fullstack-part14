# Blog App

Welcome to the Blog App.

This application lets users:

- create an account and log in
- create and browse blogs
- like blogs
- keep a personal reading list
- mark blogs as read
- generate a personal API token

## Blogs

Visit the **blogs** page to see all blogs.

## My page

Logged-in users can open **my page** to manage their reading list and API token.

---

Built with Next.js, Drizzle ORM and PostgreSQL.
